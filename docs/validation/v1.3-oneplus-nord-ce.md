## 2. Invariant Verification

The physical run verified the strict pipeline invariant:
$$\text{CONCEALED} \equiv \text{COMPOSED} = 1, \quad \text{FAILED} = 0$$

- **Seek Discontinuity Handling**: Skips across timeline positions (e.g. `seekTo(3961793)` and `onPositionDiscontinuity(reason=1)`) invoke `resetDeadlineBaseline()` and increment `DISCONT: 2`, without generating spurious `MISSED` frame counts.
- **Buffer Gating**: Network rebuffering states do not trigger artificial neural reconstruction cycles.
- **Process CPU Accounting**: Measured kernel CPU delta eliminates synthetic formula dependencies.
- **Audio Telemetry**: Playout latency dynamically tracked from system audio sync times.

## 5. Architectural Qualification (v1.3 vs. v1.4)

> **Qualification for Scientific Credibility:**  
> In **v1.3.0**, the base latent is **stream-conditioned**—modulated dynamically by presentation timestamps, frame geometry, and bitrate energy. It is **not** an encoder-derived latent extracted directly from decoded bitstream syntax elements.  
>  
> This test verifies the end-to-end systems architecture:  
> **Network / timeline event $\rightarrow$ NVC inference $\rightarrow$ Reconstructed frame $\rightarrow$ GPU composition**  
>  
> Direct learned latent extraction from the decoded video/pixel pipeline and objective visual fidelity evaluation (**PSNR, SSIM, VMAF, LPIPS**) are targeted for **v1.4.0**.
